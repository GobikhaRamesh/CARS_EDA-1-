# Exploratory Data Analysis (EDA) on Used Car Dataset

## 1. Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a used car dataset using Python. The main objective is to understand automobile data, identify patterns and relationships, detect outliers, and discover useful insights about used car prices.

The analysis is performed using Google Colab with Python data analysis and visualization libraries.

## 2. Objectives

- Understand the structure and features of the dataset.
- Identify missing values, duplicate records, and inconsistent categories.
- Clean the dataset and handle invalid values.
- Calculate descriptive statistics for numerical and categorical columns.
- Perform univariate, bivariate, and multivariate analysis.
- Identify outliers and relationships between car features.
- Create meaningful charts and derive at least five data-supported insights.

## 3. Dataset

**Dataset name:** Used Car Information

**Source:** Kaggle

**Dataset link:** https://www.kaggle.com/datasets/sanjeetsinghnaik/used-car-information

The dataset contains information about used cars. Depending on the available columns, the analysis may include:

- Car brand and model
- Manufacturing year
- Selling price
- Fuel type
- Distance travelled
- Vehicle age
- Other available automobile attributes

The dataset source and actual column names are verified during the analysis.

## 4. Technologies Used

- **Programming Language:** Python
- **Platform:** Google Colab
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Dataset Format:** CSV

## 5. Project Workflow

1. Import the required Python libraries.
2. Upload and load the dataset.
3. Inspect dataset dimensions, columns, sample rows, and data types.
4. Separate numerical and categorical variables.
5. Check missing values, duplicate rows, and inconsistent categories
